# 6.5 宏与关键字、typedef 名字冲突

## 本节讲什么

预处理 **先于** 编译；`#define` 会替换 **所有** 匹配的标识符 token，包括 typedef 名、函数名、甚至关键字（若未防护），造成全工程类型/语法错乱。

## 要点

```c
#define int long
int a;           /* → long a;  整文件 int 语义被篡改 */
```

### 规范

- 宏名 **全大写** + 项目前缀：`MYDRV_MAX_BUF`
- **禁止** `#define` 标准关键字、常用 typedef（`uint32_t`、`size_t`）
- 取消误定义：`#undef int`（极少使用，优先别定义）
