# 6.6 表查找

## 本节讲什么

K&R **符号表（keyword / identifier lookup）** 综合案例：结构体 + 自引用链表 + 字符串指针 + 查找/插入。整章工程化落地的样板。

## 要点

### 典型符号表项

```c
struct nlist {
    struct nlist *next;   /* 哈希冲突链 */
    char *name;           /* 标识符名 */
    char *defn;           /* 替换文本 */
    int type;             /* 类型码 */
};
```

### 操作流程

1. **查找**：按名字 hash 或线性扫描链表，比较 `name`
2. **插入**：新 `struct nlist` 分配，`next` 挂到桶头
3. **更新**：已存在则改 `defn` / `type`

### 设计要点

- 表项在**堆**上（`malloc`），表头数组在静态或全局
- 字符串 `name` 常指向独立拷贝或字面量
- 与预处理 `#define`、宏替换逻辑衔接（第 4 章）

## 底层映射

| 概念 | 系统对应 |
|------|----------|
| 符号表 | 链接器符号、内核 ksymtab |
| 哈希 + 链 | 内核 `hlist`、动态库 PLT |
| 插入/查找 | 设备注册、配置项字典 |

## 与后续衔接

理解「结构体描述数据 + 指针描述关系」后，读 ELF 符号表、JSON 解析树、订单簿节点同一套思维；HFT 可用固定数组 + 空闲链替代 `malloc` 以降低延迟。
