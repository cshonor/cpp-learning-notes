# 6.5 自引用结构

## 本节讲什么

结构体内部包含**指向自身类型的指针**（不能嵌套同名 struct 实体，只能嵌套指针），用于**链表**、树等动态数据结构。

## 要点

```c
struct node {
    int data;
    struct node *next;   /* 自引用：下一节点 */
};
```

- **`struct node` 不完整类型**在声明 `next` 时已足够；定义指针不需完整布局
- 不能写 `struct node next;`（无限大小）—— 只能 `struct node *next`

### 单向链表

```c
struct node *head = NULL;

/* 插入：新节点 malloc，next 指向原 head，更新 head */
```

### 双向链表

```c
struct node {
    int data;
    struct node *prev;
    struct node *next;
};
```

## 应用

| 领域 | 例子 |
|------|------|
| OS | 进程链表、空闲页块链表 |
| HFT | 订单链、事件队列节点 |
| 内核 | `list_head` 侵入式链表（进阶） |
| 设备管理 | 外设注册链表 |

## 考点

- 浅拷贝：`n2 = n1` 只复制指针，两变量指向同一节点
- 释放链表需按序 `free`，避免泄漏与 double-free
- 内核栈深度有限，过长链表遍历用迭代而非递归
