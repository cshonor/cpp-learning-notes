# 6.4 指向结构的指针

## 本节讲什么

**结构体指针**是底层代码默认姿势：`**s->member**` 等价于 **`(*s).member`**；`.` 优先级高于 `*`，故 `*s.member` 非法。

## 要点

```c
struct point { int x, y; };
struct point p = { 10, 20 };
struct point *pp = &p;

(*pp).x = 30;    /* 合法但冗长 */
pp->x = 30;      /* 惯用写法 */
```

### 箭头运算符 `->`

- 左操作数必须是**指向结构的指针**
- 编译器隐式解引用再取成员

### 函数传参

```c
void sety(struct point *p, int y)
{
    p->y = y;
}
```

- 避免拷贝；修改会反映到调用者对象
- 大型 UEFI Protocol、Linux `inode *`、`sk_buff *` 均为指向结构的指针

### 指针运算

- `p++` 若 `p` 为 `struct T *`，步长为 **`sizeof(struct T)`**（含 padding）
- 结构体数组 + 指针遍历：`for (p = arr; p < arr + n; p++)`

## 考点

- `p->member` vs `p.member` 混用错误
- 空指针解引用 `->` 崩溃
