# 5.5 字符指针与函数

## 本节讲什么

C **字符串**以 `char` 数组 + 末尾 **`'\0'`** 表示；库函数 `strlen`、`strcpy`、`strcmp` 等全部用**字符指针**实现。同时本节涵盖**返回指针的函数**及其生命周期陷阱。

## 要点

### 两种字符串存储

```c
char *s = "abc";      /* s 指向只读静态存储区，修改 *s 未定义/崩溃 */
char buf[] = "abc";   /* buf 是栈/静态数组，内容可改 */
```

- 字符串字面量 `"..."` 存**只读段**（`.rodata`）；多份相同字面量可能合并
- `char buf[] = "abc"` 在栈或全局，**可复制、可改**

### 标准库模式

- **`strlen(s)`**：遍历直到 `'\0'`
- **`strcpy(dst, src)`** / **`strncpy`**：逐字符拷贝
- **`strcmp`**：字典序比较

### 指针作为函数返回值

| 可返回 | 不可返回 |
|--------|----------|
| 指向 **`static` 局部** 的指针 | 指向**普通局部自动变量** |
| 指向 **全局/静态** 存储 | 函数返回后栈帧销毁 → **野指针** |
| 调用者提供的**缓冲区指针** | |

```c
char *bad(void)
{
    char local[] = "oops";
    return local;   /* 错误：栈已失效 */
}
```

## 示例

```c
/* 书中 swap：用指针交换两个字符串指针变量 */
void swap(char *v[], int i, int j)
{
    char *temp = v[i];
    v[i] = v[j];
    v[j] = temp;
}
```

## 考点

- 只读字面量修改 → 段错误
- 返回栈指针 → 面试必问
- `strcpy` 不检查边界 → 缓冲区溢出；内核/HFT 更常用带长度 API
