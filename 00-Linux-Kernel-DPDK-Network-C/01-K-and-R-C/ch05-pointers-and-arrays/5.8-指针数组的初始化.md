# 5.8 指针数组的初始化

## 本节讲什么

**指针数组**可在定义时用字符串字面量列表初始化；各字符串存于只读区，数组元素指向它们。K&R 月份表、关键字表是经典范例。

## 要点

```c
char *month[] = {
    "January", "February", "March",
    /* ... */
};
```

- 编译器为每个字面量分配存储，**数组元素是指向它们的指针**
- 元素个数由 initializer 个数决定
- 可配合 **`sizeof(month)/sizeof(month[0])`** 或单独 `#define` 得长度
- 与二维 `char` 数组不同：此处是「指针行」，各行长度可不同

## 对比

| | `char *names[]` | `char names[][10]` |
|---|-----------------|---------------------|
| 行宽 | 可变（字面量长度） | 固定 10 |
| 内存 | 指针 + 分散字面量 | 连续二维块 |

## 示例：行长度不一的文本表

```c
char *keywords[] = { "if", "else", "while", "for" };
```

## 与后续衔接

Shell 内建命令表、内核 syscall 名称表、策略引擎 opcode 名称，常用静态指针数组 + 二分/哈希查找。
