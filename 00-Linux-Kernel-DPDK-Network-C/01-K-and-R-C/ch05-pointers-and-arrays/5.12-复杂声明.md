# 5.12 复杂声明

## 本节讲什么

综合运用本章规则，**读懂**（必要时写出）多层指针、数组、函数返回类型的 C 声明。读 Linux、DPDK 头文件的必备技能。

**前置**：[2.4 声明围绕标识符](../ch02-types-operators-expressions/2.4-声明.md)、[5.1 指针与地址](./5.1-指针与地址.md)。

## 要点

### 1. 核心规则：声明 **围绕标识符**

C 的类型声明不是「类型名 + 变量名」两段拼起来，而是 **以标识符为中心**，`**` `[]` `()` 绑在名字上**：

> **对标识符做什么操作（解引用、取下标、调用），得到的就是它的「元素类型」或「指向类型」。**

| 声明 | 读法 | 结论 |
|------|------|------|
| `int x` | `x` 是 `int` | 整型变量 |
| `void *p` | `*p` 是 `void` | `p` 是 **void 指针** |
| `int *q` | `*q` 是 `int` | `q` 是 **int 指针** |
| `int *a[10]` | `a[10]` 的元素是 `int *` | `a` 是 **数组**，元素为 **int 指针** |
| `int (*b)[10]` | `*b` 是 `int[10]` | `b` 是 **指针**，指向 **含 10 个 int 的数组** |

**为何 `void *p` 这么写**：不是说「void 和 * 随便并排」—— 而是声明 **`p` 解引用后是 `void`**，所以 **`p` 本身是指针**。与 `int *a[10]` 同一套语法，才能和更复杂的声明保持一致。

### 2. 经典读法步骤（由内向外）

1. 找到 **标识符**（变量名 / 函数名）
2. 紧邻的 **`[]`** → 数组（`a[N]` = `a` 是数组）
3. 紧邻的 **`()`** → 函数（`f()` = `f` 是函数）
4. **`()` 改变结合**：`(*p)` 让 `*` 先绑在 `p` 上，而不是绑在更外层
5. **`*`** → 指针（`*x` 是 T → `x` 是 T 的指针）

```c
int *a[10];
/* ① 标识符 a
   ② a[10]：a 是数组
   ③ 元素类型 int* → 指针数组 */

int (*b)[10];
/* ① 标识符 b
   ② (*b)：b 是指针
   ③ *b 是 int[10] → 指向数组的指针 */
```

### 3. 示例

```c
int *f(void);           /* f 是函数，返回 int * */
int (*pf)(void);        /* pf 是指针，指向 int(void) 函数 */
char **argv;            /* argv 是数组？ 若 char **argv 单独：
                           *argv 是 char* → argv 是 char** 指针；
                           常见为 char *argv[] 即指针数组 */
int (*signal(int, void (*)(int)))(int);
/* signal 是函数：参数 int 与 void(*)(int)；
   返回「指向 void(*)(int) 的指针」—— 旧式 signal 原型 */
```

### 4. 数组指针 vs 指针数组（必记）

```c
int *a[10];      /* a：10 个 int* —— [] 先绑 a */
int (*b)[10];    /* b：指向 int[10] —— () 让 * 先绑 b */
```

| 声明 | 标识符是什么 | 记忆 |
|------|-------------|------|
| `int *a[10]` | **`a` 是数组** | 没有括号 → `[]` 紧贴名字 |
| `int (*b)[10]` | **`b` 是指针** | 有括号 → `*` 紧贴名字 |

### 5. 实用技巧

- **`typedef`** 拆解：`typedef int (*handler_t)(void *);`
- **右左法则 / cdecl**（网上工具）：复杂声明手练几次即可
- 头文件里优先 typedef 隐藏复杂度

### 6. `const` / `volatile` 与指针（延伸）

```c
const char *p;    /* *p 只读；p 本身可改指向 */
char * const p;   /* p 不可改指向；*p 可写 */
const char * const p;
```

`const` 同样 **围绕标识符**：看 `const` 紧贴的是 `*` 一侧还是变量名一侧。

## 易混点

| # | 要点 |
|---|------|
| 1 | 声明 **围绕标识符**，不是从左到右念「类型名」 |
| 2 | `void *p`：`*p` 是 void → `p` 是指针 |
| 3 | `int *a[10]`：`a` 是 **数组**；`int (*b)[10]`：`b` 是 **指针** |
| 4 | `()` 改变 `*` 与 `[]` 谁先绑在名字上 |
| 5 | `int *p, q` 只有 `p` 是指针（逗号不传播 `*`） |

4. `const char *p` 与 `char * const p` 能否 `p = "other"`？能否 `*p = 'x'`？
5. 写出「指向含 5 个 `double` 的数组的指针」的声明。
