# 5.12 复杂声明

## 本节讲什么

综合运用本章规则，**读懂**（必要时写出）多层指针、数组、函数返回类型的 C 声明。读 Linux、DPDK 头文件的必备技能。

## 要点

### 经典读法（由内向外 / 结合 `()` `[]` 优先级）

1. 变量名
2. 紧邻的 `[]` → 数组
3. 紧邻的 `()` → 函数
4. `*` → 指针

### 示例

```c
int *f(void);           /* f 是函数，返回 int * */
int (*pf)(void);        /* pf 是指针，指向 int(void) 函数 */
char **argv;            /* 指向 char* 的指针 */
int (*signal(int, void (*)(int)))(int);
/* signal 是函数：参数 int 与 void(*)(int)；
   返回「指向 void(*)(int) 的指针」—— 实际为旧式 signal 原型 */
```

### 实用技巧

- **`typedef`** 拆解：`typedef int (*handler_t)(void *);`
- **`cdecl` / 右左法则**（网上工具）：复杂声明手练几次即可
- 头文件里优先 typedef 隐藏复杂度

### 数组指针 vs 指针数组（再记）

```c
int *a[10];      /* a：10 个 int* */
int (*b)[10];    /* b：指向 int[10] 的指针 */
```

## 考点

- 面试常给一行声明，问「是什么」
- **`const` / `volatile`** 与指针组合（第 2、6 章延伸）：`const char *` vs `char * const`
