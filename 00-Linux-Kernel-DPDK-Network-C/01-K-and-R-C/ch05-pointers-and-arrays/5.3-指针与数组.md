# 5.3 指针与数组

## 本节讲什么

数组与指针在 C 中 **紧密绑定**，但 **不是同一概念**：数组名在多数表达式里 **隐式退化** 为指向首元素的指针；`a[i]` 与 `*(a+i)` 等价。必须吃透 **首地址怎么取**、**`sizeof` 陷阱**、**传函数后丢失长度** —— HFT / 内核里偏移算错、长度算错是高频 bug。

**前置**：[1.6 数组](../ch01-introduction/1.6-数组.md)、[5.1 指针与地址](./5.1-指针与地址.md)、[5.2 指针与函数参数](./5.2-指针与函数参数.md)。

## 一、数组名 vs 指针：不完全是一个概念

| | **数组名 `arr`** | **指针变量 `p`** |
|---|-----------------|-----------------|
| 本质 | 代表 **一整块连续内存**（10 个 `int`） | 变量里存 **一个地址值** |
| 多数表达式中 | **退化成** 首元素地址（`&arr[0]`） | 本来就是地址 |
| `arr++` / `p++` | `arr` **不能** 自增（退化结果是 **常量**） | `p++` **可以** 移动指向 |
| `arr = p` | ❌ 数组名不可赋值 | `p = arr` ✅ |
| `sizeof` | **整个数组** 字节数 | 指针宽度（64 位通常 8） |

```
int arr[10];   /* 连续 40 字节（假设 int=4） */
int *p;

p = arr;       /* arr 退化 → 首元素地址，类型 int * */
/* arr 不是指针变量，只是「在表达式里当首地址用」 */
```

**不完全相同**，但 **值上** 退化后的 `arr` 与 `&arr[0]` 一致 —— 都指向第一个元素。

## 二、数组名何时退化、何时不退化？

| 场景 | `arr` 行为 | 类型（`int arr[10]`） |
|------|-----------|----------------------|
| `p = arr` | 退化为首元素指针 | `int *` |
| `arr[i]`、`*(arr+i)` | 退化后做偏移 | — |
| `sizeof(arr)` | **不退化** | 整个数组大小（40） |
| `&arr` | **不退化** | `int (*)[10]`（指向整个数组） |
| 作函数实参 `f(arr)` | **退化为** `int *` | 丢失长度 10 |

> 规则：**需要「数组整体属性」（大小、数组指针类型）」时不退化；其余多数表达式退化为首元素指针。**

## 三、数组首地址怎么获得？（三种方式）

```c
int arr[10];
int *p1 = arr;        /* ① 最直接：数组名 → 首元素地址 */
int *p2 = &arr[0];    /* ② 显式取第一个元素地址，与 ① 完全等价 */
```

**① `arr`** 与 **② `&arr[0]`**：数值相同，类型都是 **`int *`**，HFT / 日常遍历 **优先用这两种**。

### ③ `&arr`：数值相同，类型不同（易踩坑）

```c
int (*p3)[10] = &arr;   /* 类型：指向「含 10 个 int 的数组」*/
```

| 写法 | 类型 | 数值 | `+1` 时步长 |
|------|------|------|------------|
| `arr` / `&arr[0]` | `int *` | 首元素地址 | `sizeof(int)`（通常 4） |
| `&arr` | `int (*)[10]` | 同样数值 | **`sizeof(arr)` = 10×4 = 40** |

```c
printf("%p\n", (void *)arr);       /* 首地址 */
printf("%p\n", (void *)&arr[0]);   /* 同上 */
printf("%p\n", (void *)&arr);      /* 数值通常相同 */
printf("%zu\n", sizeof arr);       /* 40 */
printf("%zu\n", sizeof &arr);      /* 8（指针变量大小）*/

/* 指针算术 */
int *a = arr;
int (*b)[10] = &arr;
a + 1;   /* 前进 4 字节 → &arr[1] */
b + 1;   /* 前进 40 字节 → 跳过整个 arr，指向「下一个 int[10]」概念位置 */
```

**HFT 建议**：取首元素遍历用 **`arr` 或 `&arr[0]`**；**避免** 把 `&arr` 当 `int *` 强转后做 `+i` 偏移 —— 步长错了，行情/订单数组会读飞。

完整「数组指针」`int (*p)[N]` 见 [5.6](./5.6-指针数组以及指向指针的指针.md)。

## 四、`a[i]` ≡ `*(a + i)`

```c
int a[10];
int *p = a;

a[3] = 0;
*(p + 3) = 0;     /* 同上 */

for (p = a; p < a + 10; p++)
    *p = 0;       /* 指针遍历 */
```

编译器对 `a + i` 按 **元素类型** 缩放：

| 指针类型 | `p + 1` 前进 |
|----------|-------------|
| `char *` | 1 字节 |
| `int *` | `sizeof(int)`（通常 4） |
| `double *` | 8 字节 |

详见 [5.4 地址算术运算](./5.4-地址算术运算.md)。

## 五、传数组给函数：退化 + 丢失长度（HFT 踩坑）

```c
void fill(int *buf)    /* 等价 void fill(int buf[]) */
{
    /* sizeof(buf) == 8（指针），不是原数组长度！ */
}

int arr[100];
fill(arr);             /* arr 退化为 int *，100 这个信息没了 */
```

| 写法 | 传进去的是什么 | 长度还在吗 |
|------|---------------|-----------|
| `fill(arr)` | 首元素地址 | ❌ 必须另传 `n` |
| `fill(arr, 100)` | 地址 + 显式长度 | ✅ 推荐 |
| `fill(arr, sizeof arr / sizeof arr[0])` | 仅 **实参是数组名** 时 `sizeof arr` 有效 | ✅ 常用宏 |

```c
#define ARRLEN(a) (sizeof(a) / sizeof((a)[0]))

void fill(int *buf, size_t n)
{
    for (size_t i = 0; i < n; i++)
        buf[i] = 0;
}

fill(arr, ARRLEN(arr));   /* 调用方算长度，再传入 */
```

**一旦进入函数**，形参 `buf` 的类型是 **`int *`**，`sizeof(buf)` 只剩指针宽度 —— 这是 [5.2](./5.2-指针与函数参数.md) 预告的坑的完整版。

## 六、数组 vs 指针对照总表

| | 数组 `int a[10]` | 指针 `int *p` |
|---|------------------|---------------|
| 存储 | 连续 10 个 `int` | 一个地址值 |
| `sizeof` | 40 | 8 |
| 赋值 | 不能 `a = ...` | `p = a` 可以 |
| 自增 | `a++` 非法 | `p++` 合法 |
| 传函数 | 退化为 `int *` | 本来就是 `int *` |
| 获取首地址 | `a`、`&a[0]` | `p` 本身（若已指向首元素） |

## 七、工程场景

| 场景 | 用法 |
|------|------|
| **DPDK mbuf 数据区** | 基址指针 + 偏移遍历 |
| **内核 `sk_buff`** | 数据指针 + `len` 字段（长度另存） |
| **HFT 行情快照** | `double *px = book;` 指针遍历档位，不传整表副本 |
| **帧缓冲** | 行基址 `uint32_t *row = fb + y * stride` |

零拷贝本质：**传首地址 + 长度/stride**，不复制整块数组。

## 背诵要点（精简版）

```
数组名 ≠ 指针变量；多数表达式 arr 退化为 &arr[0]
取首地址：arr 或 &arr[0]（推荐）；&arr 类型是 int(*)[N]，+1 步长整数组
sizeof(arr)=整数组；sizeof(指针形参)=8
传函数丢长度，必须另传 n 或 ARRLEN 在调用方算
a[i] == *(a+i)；p+1 步长 = sizeof(元素)
```
