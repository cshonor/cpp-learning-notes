# 5.3 指针与数组

## 本节讲什么

数组与指针在 C 中**紧密绑定**：数组名在多数表达式中**退化为**指向首元素的指针；`a[i]` 与 `*(a+i)` 等价。本章核心，必须吃透。

## 要点

- **数组名** `a`：在表达式中 ≈ **`&a[0]`**，类型为「指向元素类型的指针」
- 例外：`sizeof(a)`、对 `a` 取 `&` 时，数组名**不**退化为指针
- **`a[i]` 等价于 `*(a + i)`**；编译器按元素类型缩放偏移
  - `char *p; p+1` → 前进 **1** 字节
  - `int *p; p+1` → 前进 **`sizeof(int)`** 字节（通常 4）
- 数组**不能整体赋值**给另一数组；**不能作为函数返回值**整体返回
- 传递数组给函数：实际传**首元素指针** + 通常另传长度（或约定 `\0` 结尾）

## 示例

```c
int a[10];
int *p = a;       /* 等价于 p = &a[0] */

a[3] = 0;
*(p + 3) = 0;     /* 同上 */

for (p = a; p < a + 10; p++)
    *p = 0;
```

## 数组 vs 指针（考点）

| | 数组 `int a[10]` | 指针 `int *p` |
|---|------------------|---------------|
| 存储 | 连续 10 个 int | 一个地址 |
| `sizeof` | `10 * sizeof(int)` | `sizeof(int *)` |
| 可否 `a = p` | 否 | `p = a` 可以 |

## 与后续衔接

DPDK mbuf、内核 `sk_buff` 数据区、帧缓冲行遍历，都是「基址 + 下标/指针偏移」；零拷贝本质是传递指针而非复制整块数组。
