# 5.4 地址算术运算

## 本节讲什么

指针支持有限的算术：**加减整数**、**同类型指针相减/比较**。规则来自「指向数组元素」的抽象，违反规则即未定义行为。

## 合法运算

1. **指针 ± 整数**：向前/向后移动若干**元素**（非字节，编译器乘 `sizeof(元素类型)`）
2. **同数组内两指针相减**：得到中间**元素个数**（`ptrdiff_t`）
3. **同类型指针比较** `== != < > <= >=`：仅当指向**同一数组对象**内元素（或末尾后一位）时有定义

## 禁止 / 未定义

- **不同数组**对象的两指针相减或比较（除非碰巧同址，仍不可依赖）
- 指针 **× / ÷**（C 不允许）
- 越界访问：指向 `a[n]` 再 `*` 读写在很多情况下 UB

## 示例

```c
int a[10], *p = &a[2], *q = &a[7];
ptrdiff_t n = q - p;   /* 5 个元素 */

if (p < q)
    /* 同一数组内比较合法 */
```

## 底层场景

- **环形缓冲区**：`head`、`tail` 指针相减算占用（需处理绕回）
- **协议解析**：`payload = pkt + hdr_len`，指针偏移代替 memcpy
- **页表/ELF**：基址 + 偏移访问结构

## 与后续衔接

C99 起指针算术与 `uintptr_t` 互转用于硬件寄存器映射；须区分「字节地址」与「元素指针 +1」。
