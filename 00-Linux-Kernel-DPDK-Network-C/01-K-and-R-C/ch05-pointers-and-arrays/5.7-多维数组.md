# 5.7 多维数组

## 本节讲什么

二维数组是 **「数组的数组」**：`int a[3][4]` 先有 3 行，每行 4 个 `int`。内存仍**连续**，按行存储（row-major）。

## 要点

- **`a[i][j]`** 等价于 **`*(a[i] + j)`**，也等价于 **`*( *(a + i) + j )`**
- `a[i]` 是第 `i` 行，类型为「含 4 个 int 的数组」，在表达式中退化为 `&a[i][0]`
- **`sizeof a`** = `3 * 4 * sizeof(int)`；对二维数组名取地址得「指向整行数组的指针」
- 初始化可按行写：`{ {1,2}, {3,4} }`

## 示例

```c
int a[2][3] = { {0, 1, 2}, {3, 4, 5} };

int i, j;
for (i = 0; i < 2; i++)
    for (j = 0; j < 3; j++)
        printf("%d ", a[i][j]);
```

## 底层场景

- **帧缓冲 / GOP 显存**：`width × height` 像素，`(x,y)` → `base + y * stride + x`
- **嵌入式矩阵**、传感器二维采样
- **Miniload / ELF**：段、节区表二维索引
