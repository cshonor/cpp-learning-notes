# 5.1 指针与地址

## 本节讲什么

**指针**是存放**内存地址**的变量。`&` 取地址，`*` 解引用访问该地址上的数据。全书最难章节的起点 —— OS、UEFI、HFT、飞控底层代码都建立在此之上。

## 要点

- **`int *p;`**：`p` 是指向 `int` 的指针；`**` 与变量名结合：`*p` 是 `p` 所指的 `int`
- **`&x`**：取变量 `x` 的地址，类型为「指向 x 类型的指针」
- **类型约束**：`int *` 只能可靠地指向 `int`；不同类型指针在 64 位系统上**宽度相同**（通常 8 字节），但 **解引用访问的字节数** 由指向类型决定
- 指针必须**先赋值有效地址**再解引用；未初始化指针解引用 → 未定义行为
- **空指针**：不指向任何对象；C 用 **`NULL`**（通常是 `(void *)0`）；解引用 `NULL` 崩溃
- C++ 推荐 **`nullptr`**；纯 C 工程用 `NULL` 或 C23 的 `nullptr`（若可用）

## 示例

```c
int x = 10;
int *p = &x;

*p = 20;        /* x 变为 20 */
printf("%p\n", (void *)p);  /* 打印地址 */
```

## 考点

- `*` 在声明中与在表达式中含义不同：声明时「`p` 是指针」，表达式中「取 `p` 所指对象」
- **`void`（返回类型）** vs **`void *`（通用指针）**：前者无返回值，后者可存任意地址、**不能直接解引用** —— 见 [4.1 §3.1](../ch04-functions-and-program-structure/4.1-函数的基本知识.md)
- `void *` 解引用前须 **强转** 为 `int *`、`char *` 等；`malloc`、`read`/`write` 是典型用法（[7.8.5 malloc](../ch07-input-and-output/7.8-other-functions/7.8.5-存储管理函数.md)）
