# 2.3 常量

## 本节讲什么

源程序中**字面量**的写法：整型、浮点、字符、字符串及其在编译期的表示。

## 要点

### 整型

- **十进制**：`123`
- **八进制**：`0` 开头，如 `017` = 15
- **十六进制**：`0x` / `0X`，如 `0xFF`

### 浮点

- 含小数点或指数，如 `3.14`、`1e-2`

### 字符 `'x'`

- 类型为 `int`  promoted 的字符值；**转义**：`\n` `\t` `\0` `\\` `\"` `\xxx` 八进制、`\xhh` 十六进制

### 字符串 `"hello"`

- 底层是 **char 数组 + 末尾 `\0`**；与 1.9 衔接
- 字符串常量 Often 只读存储；修改未定义行为

## 注意

- 字符常量 `'a'` 与字符串 `"a"` **类型不同**（后者含 `\0`）
- 多字符串字面量相邻会拼接：`"hello" " world"` → `"hello world"`
