# 2.4 声明

## 本节讲什么

变量的**基础声明**语法，以及**全局（外部）**与**局部**声明在作用域上的区别（细节第 4 章展开）。

## 要点

- 形式：`类型 名字;` 或 `类型 名字 = 初值;`
- 一行可声明多个：`int x, y, z;`
- **局部**：块/函数内，默认自动存储（栈）
- **全局**：所有函数外，静态存储期，程序生命周期内存在
- 声明可带 **`const`** 等限定（ANSI）；K&R 本章侧重基本形式

## 与定义

- **声明**引入名字与类型；**定义**分配存储（第 4 章与《C 专家编程》会深挖 `extern`）
