# 2.8 自增运算符与自减运算符

## 本节讲什么

`++` `--` 的**前置**与**后置**形式，以及求值顺序差异。

## 要点

| 形式 | 含义 |
|------|------|
| `++i` | 先加 1，表达式值为**新值** |
| `i++` | 表达式值为**旧值**，再加 1 |
| `--i` / `i--` | 对称 |

- 同一表达式中**多次修改同一变量**未定义行为：`a[i++] = i;` 是经典面试/陷阱题
- 循环 `for (i = 0; i < n; i++)` 最常用后置/前置等价于单独步进时

## 示例

```c
int i = 3;
int a = ++i;  /* a=4, i=4 */
int b = i++;  /* b=4, i=5 */
```

## 与 C++

C++ 对迭代器重载 `++` 有前置「更高效」惯例；C 里仅作用于算术/指针类型（指针见第 5 章）。
