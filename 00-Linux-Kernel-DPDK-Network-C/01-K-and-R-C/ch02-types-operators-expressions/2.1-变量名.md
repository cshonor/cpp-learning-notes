# 2.1 变量名

## 本节讲什么

**标识符**（变量名、函数名等）的命名规则，以及**关键字**保留、大小写敏感等 lexical 基础。

## 要点

- 由字母、数字、下划线组成，**不能以数字开头**
- **区分大小写**：`sum` 与 `Sum` 是不同标识符
- **关键字**（`int`、`if`、`return`…）不能用作普通标识符；完整列表见附录 A
- 命名应可读；内核/DPDK 常见前缀风格（如 `rte_`、`__` 内核保留模式）在后续 GNU 扩展书展开

## 与 C++

C++ 关键字更多（`class`、`namespace`…）；写纯 C 时避免把 C++ 关键字当变量名在 `.c` 文件中混用。
