# 2.10 赋值运算符与表达式

## 本节讲什么

简单赋值 `=` 与**复合赋值** `+= -= *= /= %= &= |= ^= <<= >>=`；赋值表达式的值与优先级。

## 要点

- 赋值表达式**有值**：值为赋值后左操作数的值，可链式 `a = b = c`
- 复合赋值：`a op= b` 等价于 `a = a op b`（但左值只求值一次，对宏/副作用更安全一点）
- 位运算复合赋值在内核改寄存器极常见：`reg |= BIT(3);`
- 优先级：复合赋值低于算术、位运算，高于逗号

## 注意

- `if (x = y)` 与 `if (x == y)` 易混；良好习惯是赋值不在条件里
- 与 2.7 结合：复合赋值也会触发 usual conversions
