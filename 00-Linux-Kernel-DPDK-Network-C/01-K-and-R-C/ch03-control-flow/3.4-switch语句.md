# 3.4 switch 语句

## 本节讲什么

对**整型表达式**做多路分支：`switch (表达式)` 与若干 `case 常量:` 匹配。核心是 **break 与穿透（fall-through）** 的语义。

## 要点

- **控制表达式**必须是整型（`char`、`short`、`int`、`long` 等；C 不允许浮点 `switch`）
- **`case` 标签**必须是**整型常量表达式**（字面量、`enum` 常量、`#define` 等）
- 匹配到某 `case` 后**从该标号继续向下执行**，直到 **`break`**、**`return`**、**`goto`** 或 switch 结束
- **`default:`** 可选；无匹配且无 default 时，整个 switch 不执行任何分支
- **故意穿透**：多个 case 共用一段代码时，省略中间 `break`（需注释说明意图）

## break 与穿透

```c
switch (c) {
case '0': case '1': case '2': case '3': case '4':
case '5': case '6': case '7': case '8': case '9':
    digit = c - '0';
    break;
case EOF:
    break;
default:
    digit = -1;
    break;
}
```

无 `break` 时会「掉进」下一 case —— 有时是 bug，有时是刻意合并分支。

## 考点

- 忘记 `break` → 执行多个 case 体（内核/驱动里偶有用，业务代码多为 bug）
- `case` 后必须是**编译期常量**，不能是变量
- `switch` 与 `else if` 链等价性：离散常量多时 `switch` 常更清晰

## 与后续衔接

设备 IOCTL、协议 opcode、有限状态机转移表，都高频使用 `switch`；DPDK/内核里也会用穿透处理「一类事件统一处理」。
