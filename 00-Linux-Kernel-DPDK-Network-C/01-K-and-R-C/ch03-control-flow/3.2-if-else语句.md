# 3.2 if-else 语句

## 本节讲什么

根据条件选择执行路径：`if` 单分支、`if-else` 双分支。语法简单，但 **else 与最近未配对的 if 绑定** 是经典易错点。

## 要点

- 形式：`if (表达式) 语句` 或 `if (表达式) 语句 else 语句`
- 条件表达式**非 0 为真**，0 为假（与第 2 章关系/逻辑运算衔接）
- **else 就近匹配**：else 总是与**离它最近、且尚未匹配 else 的 if** 配对
- 多行分支务必加 `{}`，否则 else 可能「挂错」if

## 经典陷阱

```c
if (n > 0)
    if (n < 100)
        return n;
else          /* 匹配的是内层 if，不是外层！ */
    return -1;
```

正确写法：外层、内层都加块，或改用 `else if` 扁平化（见 3.3）。

## 示例

```c
if (x > y)
    printf("x is greater\n");
else
    printf("x is not greater\n");
```

## 与后续衔接

内核里大量 `if (unlikely(...))` 风格的分支；理解 else 绑定规则，才能正确阅读嵌套条件与宏展开后的代码。
