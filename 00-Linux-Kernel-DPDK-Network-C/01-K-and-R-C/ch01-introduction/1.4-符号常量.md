# 1.4 符号常量

## 本节讲什么

用 `#define` 在预处理阶段定义符号常量，替代散布在代码里的「魔法数字」。

## 要点

- `#define 名字 替换文本` —— **预处理**在编译前做文本替换，不是变量
- 提升可读性与可维护性（改一处，全文生效）
- 本章不涉及带参数的宏；复杂宏留到第 4 章预处理器

## 示例

```c
#define LOWER  0
#define UPPER  300
#define STEP   20

for (fahr = LOWER; fahr <= UPPER; fahr = fahr + STEP)
    ...
```

## 与 C++ 习惯

C++ 更倾向 `const` / `constexpr`；纯 C 项目与内核代码仍大量用 `#define` 常量与条件编译。
