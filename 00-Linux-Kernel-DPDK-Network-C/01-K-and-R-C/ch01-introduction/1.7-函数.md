# 1.7 函数

## 本节讲什么

如何定义与调用自定义函数，用**函数分解**降低主程序复杂度；示例为整数幂 `power(m, n)`。

## 要点

- 函数需先**声明**（原型）再调用，或定义写在调用之前
- 形式：`返回类型 函数名(形参列表) { 函数体 }`
- `return 表达式;` 带返回值；`return;` 用于 `void` 或无返回值习惯
- 主程序负责 I/O 与流程，计算逻辑下沉到函数——与内核「小函数、清晰边界」同构

## 示例骨架

```c
int power(int m, int n);  /* 声明 */

main()
{
    int i;
    for (i = 0; i < 10; ++i)
        printf("%d %d %d\n", i, power(2, i), power(-3, i));
    return 0;
}

int power(int base, int n)
{
    int p;
    for (p = 1; n > 0; --n)
        p = p * base;
    return p;
}
```
