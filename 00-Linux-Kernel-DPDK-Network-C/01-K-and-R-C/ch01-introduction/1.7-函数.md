# 1.7 函数

## 本节讲什么

如何 **定义、声明、调用** 自定义函数，用 **函数分解** 降低 `main` 复杂度；示例为整数幂 `power(m, n)`。除 `main` 外，**任何函数在首次调用前都必须有声明（原型）或完整定义** —— 通常写在 **本 `.c` 文件开头** 或 **头文件** 里。

## 要点

### 1. 先声明，后调用（`main` 除外）

C **没有**「先用后声明」：编译器从上到下读翻译单元，**第一次见到函数名时** 必须已经知道它的 **返回类型与参数类型**。

```c
#include <stdio.h>

int power(int m, int n);   /* 函数声明（原型）—— 通常放在文件前部或 .h */

int main(void)
{
    int i;
    for (i = 0; i < 10; ++i)
        printf("%d %d %d\n", i, power(2, i), power(-3, i));
    return 0;
}

int power(int base, int n)  /* 函数定义 —— 可在 main 之后 */
{
    int p;
    for (p = 1; n > 0; --n)
        p = p * base;
    return p;
}
```

| 方式 | 说明 |
|------|------|
| **声明在前，定义在后** | 最常见：文件顶部一组原型，`main` 在中部，函数体在后部 |
| **定义写在调用之前** | 小文件可行；大工程难维护 |
| **头文件 `#include`** | 声明放 `.h`，多个 `.c` 共享（ch4 预处理器展开） |

**`main` 特殊**：程序入口，链接器认这个名字，**不需要** 你在文件里再写 `int main(void);` 原型（当然写了也无害）。

### 2. 声明 vs 定义

```c
int power(int m, int n);              /* 声明：告诉编译器「有这么个函数」 */
int power(int base, int n) { ... }    /* 定义：给出函数体，分配代码 */
```

- **声明（原型）**：返回类型 + 函数名 + **参数类型列表**（形参名可省略）
- **定义**：声明 + **`{ 函数体 }`**
- 同一 `.c` 里 **可以** 先声明后定义；**不能** 只有调用、没有任何声明/定义

### 3. 函数形式与 `return`

```c
返回类型 函数名(形参列表)
{
    语句;
    return 表达式;   /* 非 void 必须能返回值 */
}
```

- `return 表达式;` — 带返回值
- `return;` — `void` 函数或无返回值路径
- 形参列表 **`void`** 表示无参：`int f(void);`（与 `int f();` 旧式不同，见 K&R 演进）

### 4. 分解原则

- **`main`**：流程、I/O、调用关系
- **子函数**：单一计算或单一职责（如 `power` 只做乘幂）
- 与内核「小函数、清晰边界」同构；HFT 里热路径函数与非热路径分层

### 5. 与「声明随使用」同一套思维

[1.6](./1.6-数组.md) 讲变量声明：**使用时什么类型，反推变量是什么**。  
函数声明同理：调用处 `power(2, i)` 需要编译器已知 **`power` 接受两个 `int`、返回 `int`**，否则无法生成正确调用指令（参数入栈/寄存器、返回值处理）。

函数指针声明 `int (*fp)(int, int);` 也是 **声明随使用**：`*fp` 调用后得到 `int`，故 `fp` 是指向「接受两 int 返回 int 的函数」的指针 —— 留 [ch05](../ch05-pointers-and-arrays/)。

## 完整示例骨架

```c
#include <stdio.h>

int power(int m, int n);   /* 文件开头：原型 */

int main(void)
{
    int i;
    for (i = 0; i < 10; ++i)
        printf("%d %d %d\n", i, power(2, i), power(-3, i));
    return 0;
}

int power(int base, int n)
{
    int p;
    for (p = 1; n > 0; --n)
        p = p * base;
    return p;
}
```

```bash
gcc -Wall -Wextra -std=c11 -o power_demo power_demo.c
./power_demo
```

## HFT / 底层开发的用处

1. **头文件接口**：策略引擎 `.h` 声明 API，`.c` 实现 — 改实现不改调用方
2. **编译期检查**：原型错误（参数类型不对）在编译期暴露，而非实盘才崩
3. **`static` 文件内函数**（ch4）：仅本翻译单元可见，减少符号污染

## 与 C++ 的差异

| 主题 | C（本节） | C++ |
|------|-----------|-----|
| 声明位置 | 调用前必须可见 | 同样；另有 overload、namespace |
| 无参 | `f(void)` 明确表示无参 | `f()` 与 `f(void)` 在 C++ 中都是无参 |
| 分解 | 函数 + 文件 | 另加 class、namespace |
