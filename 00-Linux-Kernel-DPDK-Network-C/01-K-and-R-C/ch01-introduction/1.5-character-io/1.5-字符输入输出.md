# 1.5 字符输入输出

## 本节讲什么

基于 `<stdio.h>` 的 **`getchar()` / `putchar()`**，不依赖指针，逐个字符处理输入流，实现四个经典 Unix 文本小工具。这是「流式 I/O」的入门：后续第 7、8 章会展开文件与系统接口。

## 要点

- `getchar()` 从 stdin 读一个字符，返回 `int`（含 EOF）；`putchar(c)` 输出一个字符
- `EOF` 表示输入结束，常与 `-1` 比较（应用 `int` 接收，避免与 `char` 混淆）
- 四个递进示例：复制 → 计字符 → 计行 → 计单词
