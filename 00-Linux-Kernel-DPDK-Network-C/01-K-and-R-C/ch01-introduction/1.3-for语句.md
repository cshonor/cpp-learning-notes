# 1.3 for 语句

## 本节讲什么

完整介绍 `for` 循环语法，并用同一温度转换案例对比 `while`，体会 `for` 如何把「初始化、条件、步进」收在一处。

## 要点

- `for (初始化; 条件; 步进) 语句` —— 三部分都可省略，但分号不能少
- 与 `while` 等价表达时，`for` 往往更紧凑、更易读（尤其已知循环次数）
- 循环体可以是单语句或 `{ ... }` 代码块

## 对比

| | while | for |
|---|--------|-----|
| 典型场景 | 条件驱动、步进分散 | 计数、遍历、表驱动 |
| 温度表 | 初始化在循环外 | 初始化写在 `for` 头 |

复用 1.2 的温度转换逻辑，仅把循环改写为 `for` 即可。
