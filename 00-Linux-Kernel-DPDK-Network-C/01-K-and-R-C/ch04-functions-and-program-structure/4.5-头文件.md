# 4.5 头文件

## 本节讲什么

**多文件工程**的标准做法：每个 `.c` 单独编译成 `.o`，链接器合并；**头文件 `.h`** 集中声明，供 `#include` 复用。Linux 内核、EDK2、DPDK 项目结构都遵循同一套规则。

## 要点

### 编译链接流程

```
main.c  ──→ main.o  ─┐
utils.c ──→ utils.o ─┼──→ 链接器 ──→ a.out
```

- **编译单元** = 一个 `.c` 经预处理后的一次编译
- 链接阶段解析跨文件的函数、全局变量符号

### 头文件放什么

- 函数**原型**
- `#define` 宏、常量
- `typedef`、结构体声明
- **`extern` 全局变量声明**（不放定义）

### 单定义规则（ODR 的 C 版）

C **没有** `public` / `private`，靠 **`static`（内部链接）** 与 **`extern`（外部链接声明）** 控制可见性。

- 每个 **外部链接** 符号在整个程序中 **只能有一处定义**
- 其余文件用 **`extern` 声明**；**不能** 再写第二个 `int num;`
- **`a.c` 和 `b.c` 都写 `int num;`** → 链接 **`multiple definition`**，程序过不了
- 头文件被多个 `.c` include 时，**不能** 写 `int num = 0;`（每 include 一次算一份定义），应写 **`extern int num;`**

### 全局变量：头文件 + 单 `.c` 定义（规范模板）

```c
/* common.h */
#ifndef COMMON_H
#define COMMON_H
extern int num;           /* 声明：可出现在多个 .c（经 include） */
#endif

/* exactly_one.c —— 全程序唯一定义 */
#include "common.h"
int num = 0;

/* other.c */
#include "common.h"
void f(void) { num++; }  /* 直接用，不必再 extern */
```

**私有副本**：某 `.c` 若要自己的 `num` 且不与全局冲突 → `static int num;`（[4.3 §7](../4.3-外部变量.md)）。

### include 守卫

```c
#ifndef MYHDR_H
#define MYHDR_H
/* 内容 */
#endif
```

防止同一头文件被重复展开。

## 示例

```c
/* stack.h */
#define MAXVAL 100
int push(int f);
int pop(void);
```

```c
/* stack.c */
#include "stack.h"
static int sp = 0;      /* 本文件私有 */
static int val[MAXVAL];

int push(int f) { /* ... */ }
int pop(void)    { /* ... */ }
```
