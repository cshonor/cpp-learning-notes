# 4.3 外部变量

## 本节讲什么

**外部变量**定义在所有函数之外，具有**文件作用域**（默认）和**程序生命周期**，用于在函数之间共享状态。与局部自动变量对比，理解「谁可见、活多久」是读内核全局变量的前提。

## 要点

### 局部自动变量

- 在函数（或块）内声明，**仅块内可见**
- 通常在**栈**上分配，函数返回后销毁
- 每次调用重新创建（除非 `static`，见 4.6）

### 外部变量

- 在**所有函数外**定义：`int buf[100];`
- **静态存储区**，程序启动到结束一直存在
- 同一文件内所有函数可访问；其他文件通过 **`extern` 声明** 访问（见 4.4、4.5）

### 跨函数/跨文件通信

| 方式 | 特点 |
|------|------|
| 参数 + 返回值 | 接口清晰，首选 |
| 外部全局变量 | 简单但耦合高、难测试 |
| 文件 I/O | 进程间或持久化场景 |

## 底层场景

- **Linux 内核**：大量全局状态（调度器、网络命名空间）
- **HFT**：全局行情队列、共享 ring buffer 索引
- **飞控**：全局传感器融合结果、模式标志

## 示例

```c
int bufpos = 0;        /* 外部变量定义 */
char buf[BUFSIZ];

void append(int c)
{
    if (bufpos < BUFSIZ)
        buf[bufpos++] = c;
}
```

## 与后续衔接

滥用全局变量是 bug 温床；工程上应用 `static` 限制可见性（4.6），或封装成「单文件模块 + 访问函数」。第 5 章起会用指针在函数间传递缓冲区，减少全局依赖。
