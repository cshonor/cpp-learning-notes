# 4.6 静态变量

## 本节讲什么

**`static` 存储类**有两种截然不同的效果：修饰**局部变量**改变生命周期；修饰**全局/函数**改变链接属性。内核用后者隔离文件私有实现，用前者保存跨调用状态。

## 要点

### `static` 局部变量

- 存储在**静态存储区**，非栈
- **程序运行期间一直存在**；函数返回后不销毁
- **仅首次**执行到声明时初始化；之后调用保留上次的值
- 作用域仍限于函数内 —— **外部不可见**

```c
int counter(void)
{
    static int count = 0;   /* 只初始化一次 */
    return ++count;
}
```

### `static` 全局变量 / 函数

- **内部链接**：符号**仅限当前 `.c` 文件**
- 对外隐藏，避免命名冲突、缩小 API 表面
- Linux 驱动、UEFI 模块中大量 `static` 辅助函数

### 对比表

| 声明 | 存储 | 可见性 | 生命周期 |
|------|------|--------|----------|
| 局部自动 `int x` | 栈 | 块内 | 调用期间 |
| 局部 `static int x` | 静态区 | 块内 | 整个程序 |
| 全局 `int x` | 静态区 | 全程序（可 extern） | 整个程序 |
| 全局 `static int x` | 静态区 | 仅本文件 | 整个程序 |

## 考点

- 面试常问：**`static` 局部 vs 全局 `static`** —— 前者块作用域，后者文件作用域
- 线程安全：`static` 局部计数器在多线程下需加锁（后续并发章节）

## 与后续衔接

HFT 可用 `static` 隐藏策略模块内部状态机；内核 `static struct` 单例驱动数据是常见模式。
