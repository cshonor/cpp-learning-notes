# 4.6 静态变量

## 本节讲什么

**`static` 存储类**有两种截然不同的效果：修饰 **局部变量** 改变 **生命周期**；修饰 **文件级变量/函数** 改变 **链接属性（可见范围）**。内核用后者隔离文件私有实现，用前者保存跨调用状态。

**前置**：[4.3 外部变量](./4.3-外部变量.md)、[4.4 作用域规则](./4.4-作用域规则.md)。

## 要点

### 1. `static` 局部变量

- 存储在 **静态存储区**（非栈，见 [4.3.1](./4.3.1-程序内存布局.md)）
- **程序运行期间一直存在**；函数返回后 **不销毁**
- **仅首次** 执行到声明时初始化；之后调用保留上次的值
- **作用域** 仍限于函数内 —— 名字 **外部不可见**

```c
int counter(void)
{
    static int count = 0;   /* 只初始化一次 */
    return ++count;
}
```

### 2. `static` 外部变量：限制 **跨文件** 作用域（≠ 跨文件外部变量）

文件顶层（函数外）定义时加 `static`，表示 **这个变量只能在本 `.c` 里用** —— **内部链接**。它 **存储在全局/静态区**、**静态存储期** 与无 `static` 全局相同，但 **不能被其他文件 `extern` 引用**，因此 **不算** 严格意义上可跨文件共享的 **外部变量**（[4.3 §1.1](./4.3-外部变量.md)）。

#### 对比：`int num` vs `static int num`（在 `a.c` 定义）

```c
/* === a.c：普通外部变量 === */
int num;

/* b.c、c.c 使用前声明即可 */
extern int num;    /* ✅ 能访问 a.c 里的 num */
```

```c
/* === a.c：static 外部变量 === */
static int num;

/* b.c */
extern int num;    /* ❌ 无效：链接器找不到可供外部的 num */
```

| `a.c` 定义 | `b.c` 里 `extern int num;` |
|------------|---------------------------|
| `int num;` | **可以** —— 跨文件共享一份内存 |
| `static int num;` | **不可以** —— `num` 被锁在 `a.c`，别的文件 **就算写 extern 也访问不到** |

**记忆**：`static` 加在 **外部变量定义** 上 = **对外隐藏**，只给 **本翻译单元** 用；与「全程不销毁」不矛盾 —— 生命周期仍是程序全程，只是 **链接范围** 缩小到单文件。

### 3. `static` 函数

```c
static void helper(void)   /* 仅本 .c 可调用 */
{
    ...
}
```

- 函数 **定义** 前加 `static` → **内部链接**，其他 `.c` **不能** 调用（也不必在 `.h` 暴露）
- Linux 驱动、UEFI 模块中大量 `static` 辅助函数

### 4. 对比表

| 声明 | 存储 | 名字可见范围 | 链接 | 生命周期 |
|------|------|-------------|------|----------|
| 局部自动 `int x` | 栈 | 块内 | — | 调用期间 |
| 局部 `static int x` | 静态区 | 块内 | — | 整个程序 |
| 全局 `int x` | 静态区 | 全程序可 `extern` | **外部** | 整个程序 |
| 全局 `static int x` | 静态区 | **仅本 `.c`** | **内部** | 整个程序；**非** 跨文件外部变量 |

## 易混点

| # | 要点 |
|---|------|
| 1 | **`static` 局部**：活全程，**名** 仍只在函数内 |
| 2 | **`static` 全局**：活全程、在全局区，但 **名** 只在本 `.c`；**非** 跨文件外部变量 |
| 3 | `a.c`、`b.c` 各 `int num;`（无 static）→ 链接 **重复定义** |
| 4 | 一文件 `int num`、另一文件 `static int num` → `extern` 只指向 **非 static** 那份 |
| 5 | 面试常问：**`static` 局部 vs 全局 `static`** —— 前者块作用域，后者文件作用域 |

## HFT / 内核提示

- 模块内部状态机：`static` 全局 + `static` 函数封装，**.h 只暴露必要 API**
- 线程安全：`static` 局部计数器在多线程下需加锁
- 内核 `static struct` 单例驱动数据是常见模式
