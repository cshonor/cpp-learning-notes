# 4.4 作用域规则

## 本节讲什么

**作用域**决定名字在哪些位置可见；**链接（linkage）**决定符号能否跨翻译单元（`.c` 文件）合并。本章重中之重，内核与 UEFI 里 `static` / `extern` 天天见。

## 要点

### 作用域层次

| 层次 | 说明 |
|------|------|
| **块作用域** | 块内 `{ }` 声明的变量/类型 |
| **函数作用域** | 标号（`goto` 目标） |
| **文件作用域** | 函数外声明，从声明点到文件末尾 |

- **内层可遮蔽外层**同名变量；离开内层块后外层名字恢复可见

### `extern`

- **声明**（不是定义）外部变量或函数：符号在**其他翻译单元**或本文件别处**定义**
- 多文件协作：`a.c` 定义，`b.c` 写 `extern int count;` 后使用

### `static` 与链接（与 4.6 配合）

- **`static` 函数 / 全局变量**：**内部链接** —— 仅当前 `.c` 可见，链接器不导出符号
- 无 `static` 的全局符号：**外部链接** —— 全程序唯一，其他文件可 `extern`

## 示例

```c
/* file1.c */
int shared = 1;           /* 外部链接，全程序可见 */
static int hidden = 2;    /* 仅 file1.c 可见 */

static void helper(void) { /* 仅本文件可调用 */
    /* ... */
}
```

```c
/* file2.c */
extern int shared;        /* 使用 file1.c 中的定义 */

void use(void)
{
    shared++;
}
```

## 考点（面试高频）

- **`static` 两种用法**：局部变量（生命周期延长）vs 文件作用域（隐藏符号）
- **`extern` 只声明不分配存储**；定义只能有一处（单定义规则，见 4.5）
- 头文件里写 `extern int x;`，某一个 `.c` 写 `int x = 0;`
