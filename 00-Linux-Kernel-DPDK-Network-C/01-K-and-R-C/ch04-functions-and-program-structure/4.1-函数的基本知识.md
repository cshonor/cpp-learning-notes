# 4.1 函数的基本知识

## 本节讲什么

C 程序由函数构成：`main` 是入口，其余函数把逻辑拆成可复用模块。掌握 **返回类型写法**、完整语法、**值传递**、**声明 vs 定义**，是多文件工程与内核代码的基础。

**前置**：[1.7 函数](../ch01-introduction/1.7-函数.md)、[2.4 声明](../ch02-types-operators-expressions/2.4-声明.md)。

## 要点

### 1. 返回类型写在函数名 **左边**

C 里函数的 **返回值类型** 写在 **函数名左侧**：

```c
int add(int a, int b)
/*↑ 返回类型   ↑ 函数名   ↑ 形参列表 */
{
    return a + b;
}
```

| 部分 | 位置 | 示例 |
|------|------|------|
| **返回类型** | 函数名 **之前** | `int`、`void`、`float *`、`struct node` |
| **函数名** | 形参列表 **之前** | `add`、`main`、`read_pkt` |
| **形参列表** | `()` 内 | `(int a, int b)`、`(void)` |
| **函数体** | `{ ... }` | 语句与 `return` |

**声明（原型）** 与 **定义** 都遵循同一顺序 —— 返回类型始终在函数名左边：

```c
int add(int a, int b);              /* 声明：末尾分号，无函数体 */

int add(int a, int b)               /* 定义：带函数体 */
{
    return a + b;
}
```

### 2. 省略返回类型：老标准默认 `int`，现代应显式写出

K&R 时代允许 **不写** 返回类型，编译器 **默认按 `int` 处理**：

```c
/* 老式写法 —— 等价于 int add(...) */
add(a, b)
int a, b;
{
    return a + b;
}
```

| 时代 | 行为 |
|------|------|
| **老 C / K&R** | 省略返回类型 → **隐式 `int`** |
| **C99 及以后** | 旧式定义已淘汰；**必须写返回类型** |
| **现代编译器**（`-Wall`） | 省略或旧式写法 → **警告甚至报错** |

**工程规范**：**始终显式写出返回类型**，不要依赖隐式 `int`：

```c
int add(int a, int b);    /* 对 */
void log_msg(const char *s);
/* add(int a, int b);     错：现代 C 不接受 */

int main(void)            /* main 也建议写 int，参数写 void 表无参 */
{
    return 0;
}
```

`main` 省略返回类型时老编译器默认 `int main()` —— 见 [1.1 入门](../ch01-introduction/1.1-入门.md)；新代码一律 **`int main(void)`** 或 **`int main(int argc, char *argv[])`**。

### 3. 完整形式与 `return`

```c
返回类型 函数名(形参列表)
{
    语句;
    return 表达式;   /* 非 void：应保证有返回值路径 */
}
```

| 返回类型 | `return` 用法 |
|----------|---------------|
| **`int` 等整型/浮点/指针** | `return 表达式;` — 表达式 **转换为** 声明的返回类型 |
| **`void`** | `return;` 或直接落到 `}` —— **无返回值** |

- **`return 表达式;`** 结束函数并带回值
- 执行到函数末尾的 `}`（非 `void`）→ 等价于 **`return;`**，返回值 **未定义** —— **应避免**
- **`return` 表达式会转换为函数返回类型**，可能精度丢失（`int` 函数里 `return 3.14` → `3`）

```c
int max(int a, int b)
{
    return a > b ? a : b;
}

void greet(const char *name)
{
    printf("Hello, %s\n", name);
    return;          /* 可写可不写 */
}
```

### 4. 值传递（call by value）

C 默认 **按值传递**：形参是实参的 **副本**，函数内改形参 **不影响** 调用者的变量。

```c
void swap_wrong(int x, int y)
{
    int t = x;
    x = y;
    y = t;           /* 只交换了副本 */
}
```

要在函数内修改调用者数据 → 传 **指针**（第 5 章）或 **用返回值** 带回结果。

### 5. 声明（原型）vs 定义

| | 声明（原型） | 定义 |
|--|-------------|------|
| 形式 | `int f(int a);` | `int f(int a) { ... }` |
| 函数体 | **无** | **有** `{ }` |
| 作用 | 让编译器在 **调用前** 知道签名 | 生成实际机器码 |
| 次数 | 可 **多次** 声明 | 全程序 **一次** 定义 |

**调用出现在定义之前时，必须先有声明或完整定义** —— 详见 [1.7](../ch01-introduction/1.7-函数.md)。

```c
int max(int a, int b);   /* 声明 */

int main(void)
{
    int m = max(3, 5);   /* 调用：编译器已见过原型 */
    return 0;
}

int max(int a, int b)    /* 定义 */
{
    return a > b ? a : b;
}
```

## 易混点

| # | 要点 |
|---|------|
| 1 | 返回类型在函数名 **左边**：`int add(...)` |
| 2 | 老标准省略返回类型 → 隐式 **`int`**；现代 **必须显式写** |
| 3 | `void` = 无返回值；非 `void` 应有 **`return` 表达式** |
| 4 | 声明与定义 **返回类型、参数类型** 必须一致 |
| 5 | 形参是 **副本** —— 值传递 |

## HFT / 内核提示

- 头文件 `.h`：**返回类型 + 函数名 + 参数列表** 组成 API 契约；改返回类型 = **破坏 ABI**，须版本化
- 热路径：`static inline int clamp(int x, int lo, int hi)` —— 返回类型显式，便于内联
- 禁用隐式 `int`：开 `-Wimplicit-int` / `-Werror=implicit-int`（GCC）在 CI 里拦遗留代码
