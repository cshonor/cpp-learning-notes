# 3.7 break 与 continue

## 本节讲什么

在循环和 `switch` 中改变正常控制流：**break** 跳出当前层；**continue** 跳过本轮剩余语句，进入下一轮循环。

## 要点

### break

- 用于 **`switch`**：结束 switch，不再执行后续 case
- 用于 **循环**（`while` / `for` / `do-while`）：**跳出最内层** enclosing 循环
- 只跳一层；多层嵌套需多次 break 或改用 `goto`（3.8）

### continue

- 仅用于**循环**（不能用于 switch）
- 跳过本次迭代**剩余语句**，执行下一次条件判断（while/for）或步进后再判断（for 先步进再条件，取决于写法位置）
- 在 `for` 中：`continue` 仍会执行**步进部分**

## 示例

```c
for (i = 0; i < n; i++) {
    if (a[i] < 0)
        continue;   /* 跳过负数 */
    sum += a[i];
}

for (;;) {
    c = getchar();
    if (c == EOF)
        break;      /* 退出循环 */
    /* 处理 c */
}
```

## 考点

- `break` 只出**一层**循环；外层仍继续
- 滥用 `continue` 会使逻辑跳跃，可读性变差；简单过滤可接受，复杂流程考虑重构
- 与 `return`、`goto` 区别：`return` 离开整个函数

## 与后续衔接

解析协议、扫描缓冲区时常见「遇错 break / 遇分隔 continue」；内核循环里 `break` 退出等待也极其常见。
