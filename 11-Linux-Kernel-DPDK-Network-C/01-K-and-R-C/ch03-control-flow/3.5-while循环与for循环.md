# 3.5 while 循环与 for 循环

## 本节讲什么

回顾第 1 章已用过的循环，系统梳理 **`while`** 与 **`for`** 的等价关系及选用场景：遍历、计数、条件驱动。

## 要点

### while

```c
while (条件)
    语句;
```

先判断条件，为真则执行循环体，再回头判断。条件为假时一次都不执行。

### for

```c
for (初始化; 条件; 步进)
    语句;
```

等价于：

```c
初始化;
while (条件) {
    语句;
    步进;
}
```

- 三部分**任意可省略**，但分号保留：`for (;;)` 即无限循环
- 初始化、步进可以是逗号表达式或空

## 选用建议

| 场景 | 倾向 |
|------|------|
| 已知次数、下标遍历 | `for` |
| 读直到 EOF、等事件、条件在循环内才明确 | `while` |
| 无限服务循环（内核线程、行情泵） | `while (1)` 或 `for (;;)` |

## 示例

```c
/* 字符计数 — while */
while ((c = getchar()) != EOF)
    ++nc;

/* 同上 — for */
for (nc = 0; (c = getchar()) != EOF; ++nc)
    ;
```
