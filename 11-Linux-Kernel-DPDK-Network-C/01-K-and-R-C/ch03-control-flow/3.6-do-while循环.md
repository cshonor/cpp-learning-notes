# 3.6 do-while 循环

## 本节讲什么

**先执行循环体，再判断条件**；条件为真则继续。与 `while` 的关键区别：**至少执行一次**。

## 要点

- 形式：`do 语句 while (表达式);` —— 末尾分号**不能少**
- 条件为真继续，为假退出
- 适合「先做一次，再根据结果决定是否继续」的逻辑
- 循环体是单语句时也要写清楚；复杂体用 `{}`

## 与 while 对比

| | while | do-while |
|---|--------|----------|
| 判断时机 | 每次迭代**前** | 每次迭代**后** |
| 最少执行次数 | 0 | 1 |
| 典型场景 | 可能零次（空输入、已满足退出条件） | 菜单、至少读一次、重试直到成功 |

## 示例

```c
do {
    printf("enter a number: ");
} while (scanf("%d", &n) != 1 || n < 0);
```

## 与后续衔接

标准库里部分「读字符再处理」的模式可用 `do-while`；内核里相对少见，但理解语义有助于读遗留代码与宏展开。
