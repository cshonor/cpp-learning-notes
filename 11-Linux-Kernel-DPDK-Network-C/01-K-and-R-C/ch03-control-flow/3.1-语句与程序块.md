# 3.1 语句与程序块

## 本节讲什么

C 程序由**语句**组成；多条语句可用大括号 `{}` 合成**复合语句（块）**，形成独立作用域。理解块是读懂 `if`、循环、函数体的前提。

## 要点

- **语句**以分号 `;` 结束（表达式语句、空语句 `;`、控制流语句等）
- **复合语句** `{ 声明; 语句; ... }` 在语法上**视为一条语句**，可出现在任何只允许单语句的位置
- **块作用域**：块内声明的变量从声明处到块结束可见；离开块后标识符失效
- C89 要求变量声明写在块**开头**；C99 起可在块内任意位置声明（更接近 C++）
- 单独 `{}` 可创建局部作用域，限制临时变量生命周期

## 示例

```c
{
    int x = 1;
    printf("%d\n", x);
}  /* x 在此不可见 */

if (n > 0) {
    int i;
    for (i = 0; i < n; i++)
        /* ... */
}  /* i 的作用域限于 if 的块内 */
```

## 与后续衔接

函数体本身就是块；第 4 章讲函数时，参数与局部变量都遵循同一套块作用域规则。
