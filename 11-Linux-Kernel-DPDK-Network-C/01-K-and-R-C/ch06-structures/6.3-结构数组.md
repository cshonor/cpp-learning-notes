# 6.3 结构数组

## 本节讲什么

**结构体数组**批量存储同类复合数据：设备列表、内存映射描述符、传感器采样、行情快照队列等。

## 要点

```c
struct key {
    char *word;
    int count;
} keytab[100];

keytab[i].word = "auto";
keytab[i].count++;
```

- 元素访问：**`keytab[i].member`**
- 初始化可按元素列表：`struct point pts[] = { {0,0}, {1,2} };`
- 数组名在表达式中退化为指向首元素的指针（同第 5 章）
- 可与其他类型组合：**结构体数组的指针**、**含数组成员的结构体**

### 嵌套 + 数组

```c
struct memdesc {
    uint64_t phys_start;
    uint64_t num_pages;
    uint32_t type;
};

struct memdesc map[128];   /* UEFI MemoryMap 数组 */
```

## 底层场景

| 场景 | 例子 |
|------|------|
| UEFI | `GetMemoryMap` 返回描述符数组 |
| HFT | 固定长度行情 ring 缓冲 `Quote quotes[N]` |
| 飞控 | IMU 采样历史 `Sample buf[FS]` |
| 内核 | PCI 设备表、进程 `task_struct` 数组（概念上） |

## 与后续衔接

遍历结构体数组常配合指针：`for (p = keytab; p < keytab + N; p++)`；注意 `sizeof` 与 `#pragma pack` 对步长的影响。
