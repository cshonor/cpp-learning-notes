# 6.2 结构与函数

## 本节讲什么

结构体作为**函数参数**与**返回值**：C 允许按值传递/返回整个结构体，但大对象拷贝昂贵。内核、HFT 普遍传**指针**以避免整块复制。

## 要点

### 按值传递

```c
struct point makepoint(int x, int y)
{
    struct point p;
    p.x = x;
    p.y = y;
    return p;
}

void printpoint(struct point p)  /* 拷贝一份 p */
{
    printf("%d, %d\n", p.x, p.y);
}
```

- 传参、返回都会**复制整个结构体**（成员逐一拷贝）
- 小结构体（几个标量）可接受；大结构体 → 栈与寄存器压力大

### 传指针（推荐）

```c
void printpoint(const struct point *p)
{
    printf("%d, %d\n", p->x, p->y);
}
```

- **只拷贝一个指针宽度**，HFT / 内核标准写法
- 只读接口加 **`const`**，防止误改

### 对比

| 方式 | 开销 | 能否改调用者结构体 |
|------|------|---------------------|
| `f(struct s x)` | 拷贝整块 | 否（改副本） |
| `f(struct s *p)` | 拷贝指针 | 是（通过 `p->`） |

## 底层场景

- **HFT 订单/行情**：传 `Order *` / `Quote *`，禁止大 struct 值传递
- **UEFI**：Protocol 接口第一个参数常为 `This` 指针
- **驱动**：`read/write` 的 `file *`、`device *`
