# 1.9 字符数组

## 本节讲什么

C **字符串**的本质：以 **`'\0'`（NUL）** 结尾的 `char` 数组；示例为读取多行输入并找出**最长一行**。

## 要点

- 字符串常量 `"hello"` 在内存中含 `'h','e','l','l','o','\0'`
- 字符数组可读写；用下标或逐字符读写，直到 `\0` 或行结束
- 最长行程序：维护当前行长度与最大长度、必要时拷贝最长行内容到缓冲区
- 本章用固定大小数组存一行；无动态分配、无 `string.h` 高级接口

## 与 C++ `std::string`

| | C（本章） | C++ |
|---|-----------|-----|
| 表示 | `char buf[N]` + `\0` | `std::string` |
| 长度 | 需自己维护或 `strlen` | `.size()` |
| 边界 | 缓冲区溢出风险 | 相对安全 |
