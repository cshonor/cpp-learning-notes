# 1.1 入门 Getting Started

## 本节讲什么

从经典 Hello World 出发，认识 C 程序的最小骨架：头文件、`main`、标准输出，以及如何把源文件编译成可执行程序。

## 要点

- C 程序由**函数 + 变量**构成；`main` 是程序**唯一入口**，操作系统通过调用它启动程序
- `#include <stdio.h>` 引入标准 I/O 声明，使 `printf` 等可用
- `printf` 格式化输出；`\n` 换行，还有 `\t` 制表、`\b` 退格、`\"` 双引号、`\\` 反斜杠等转义
- **字符串常量**用双引号；编译 → 链接 → 运行是基本工作流

## 示例

```c
#include <stdio.h>

main()  /* K&R 写法；ANSI C 推荐 int main(void) */
{
    printf("hello, world\n");
}
```

## 与 C++ 的差异（已有 C++ 基础时）

- 无 `iostream`，I/O 走 `<stdio.h>` 的 `printf` / `scanf`
- 早期 K&R 允许 `main()` 省略返回类型（默认为 `int`）；现代 C 应写 `int main(void)`
