# 1.6 数组

## 本节讲什么

一维数组的声明、下标访问与初始化；用数组统计各类字符出现次数（数字 0~9、空白、其他）。

## 要点

- 声明：`int ndigit[10];` —— 下标从 0 开始，长度为 10 则合法下标 0~9
- 与 1.5 的 `getchar` 循环结合：`if (c >= '0' && c <= '9') ++ndigit[c-'0'];`
- 空白与其他字符分桶统计，体会**聚合计数**模式
- 本章数组下标为**整型表达式**；数组名与指针的关系留到第 5 章

## 示例思路

```c
int ndigit[10];  /* 0-9 计数 */
/* 读字符循环中 */
if (c >= '0' && c <= '9')
    ++ndigit[c - '0'];
else if (c == ' ' || c == '\n' || c == '\t')
    ++whitespace;
else
    ++others;
```

## 注意

- 数组元素未显式初始化时，静态存储为 0；局部数组初值不确定（ANSI 前更需小心）
- 越界访问 undefined behavior，内核/DPDK 代码中同样致命
