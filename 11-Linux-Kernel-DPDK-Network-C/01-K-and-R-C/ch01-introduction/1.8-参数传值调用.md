# 1.8 参数传值调用

## 本节讲什么

C 的**核心规则**：函数参数永远是**传值调用（call by value）**——形参是实参值的副本，在函数内改形参**不会**影响调用方的变量。

## 要点

- 调用时实参表达式求值，结果**拷贝**给形参；形参与实参占用不同存储
- 因此 `swap(a, b)` 若只交换形参，无法交换调用者的 `a`、`b`（除非传指针，本章不讲）
- Java、Python 等对对象引用与 C 的「纯传值」不同；从 C++ 来需刻意剥离「引用传参」习惯
- 数组作实参时会发生**退化**（第 5 章详述），本章仍按「值传递」心智模型理解

## 经典反例

```c
void swap(int x, int y)
{
    int temp = x;
    x = y;
    y = temp;   /* 只交换了副本 */
}
```

调用 `swap(i, j)` 后，`i`、`j` 不变。

## 学习意义

- 理解为何 later 需要指针：为了**共享存储**或**修改调用方对象**
- 内核 API 里大量 `struct foo *arg` 即在此需求上构建
