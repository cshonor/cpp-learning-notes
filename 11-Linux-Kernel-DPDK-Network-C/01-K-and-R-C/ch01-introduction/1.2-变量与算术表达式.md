# 1.2 变量与算术表达式

## 本节讲什么

引入基础类型与变量声明，用四则运算和简单控制流完成第一个「有用」程序——温度转换表。

## 要点

- 基础类型：`int`（整数）、`float`（浮点）；先声明、后使用
- 四则运算符 `+ - * /`，注意**优先级**与括号
- `if` 做条件判断；`while` 做循环——本章控制流仅此两种雏形
- 典型模式：初始化 → 循环体计算 → 更新循环变量 → 输出

## 示例骨架（华氏 → 摄氏）

```c
int fahr;
for (fahr = 0; fahr <= 300; fahr = fahr + 20)
    printf("%3d %6.1f\n", fahr, (5.0/9.0)*(fahr-32));
```

整型与浮点混算时，注意常量写 `5.0/9.0` 避免整数截断。
