# 5.2 指针与函数参数

## 本节讲什么

C **只有值传递**（第 4 章）。要在函数内**修改调用者的变量**，必须传**指针**（或数组首地址）：拷贝的是地址本身，通过 `*` 间接改写原对象。

## 要点

| 传参方式 | 拷贝内容 | 能否改外部变量 |
|----------|----------|----------------|
| `void f(int x)` | `x` 的副本 | 否 |
| `void f(int *px)` | 指针副本（地址值） | 是，通过 `*px = ...` |

- 形参指针与实参指针**不是同一个指针变量**，但**指向同一对象**
- 交换两变量、返回多个结果、输出参数，内核/驱动里极常见
- 数组作参数时实际传**首元素地址**（见 5.3），同样可被函数修改元素

## 示例

```c
void swap(int *px, int *py)
{
    int t = *px;
    *px = *py;
    *py = t;
}

int main(void)
{
    int a = 1, b = 2;
    swap(&a, &b);   /* a=2, b=1 */
    return 0;
}
```

## 底层场景

- **内核**：`copy_to_user(buf, kbuf, len)` —— 通过指针写用户缓冲区
- **驱动**：寄存器读写传 `volatile uint32_t *reg`
- **HFT**：环形队列传 `head`/`tail` 指针以便原地更新

## 与后续衔接

传指针不等于传引用（C++ `&`）；仍要区分「改指针本身」与「改指针所指」，`*` 与 `&` 组合是后续 bug 高发区。
