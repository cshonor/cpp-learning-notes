# 5.10 命令行参数

## 本节讲什么

**`main(int argc, char *argv[])`**：`argc` 为参数个数，`argv` 为指向各参数字符串的指针数组。HFT 工具、UEFI 应用、OS loader 用命令行控制启动行为。

## 要点

- **`argv[0]`**：程序名（可含路径）
- **`argv[1]` … `argv[argc-1]`**：后续参数
- **`argv[argc]`**：标准保证为 **`NULL`**（哨兵，便于遍历）
- 参数均为**字符串**；数值需 `atoi` / `strtol` 等转换
- 环境变量：`extern char **environ;`（POSIX，非 K&R 核心但工程常用）

## 示例

```c
int main(int argc, char *argv[])
{
    int i;
    for (i = 1; i < argc; i++)
        printf("%s%s", argv[i], (i < argc - 1) ? " " : "\n");
    return 0;
}
```

用法：`prog -v input.txt` → `argc==3`，`argv[1]=="-v"`，`argv[2]=="input.txt"`。

## 底层场景

| 场景 | 典型用法 |
|------|----------|
| HFT | 配置文件路径、策略 ID、dry-run 开关 |
| UEFI shell / 工具 | 加载镜像路径、调试级别 |
| OS loader | 内核命令行、initrd 路径 |
