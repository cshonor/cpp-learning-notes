# 5.11 指向函数的指针

## 本节讲什么

**函数指针**保存函数入口地址，用于回调、表驱动分发、调度器。与「返回指针的函数」不同 —— 面试必区分。

## 要点

### 返回指针的函数（指针函数）

```c
char *strcpy(char *dst, const char *src);  /* 返回 char * */
```

### 函数指针

```c
int (*fp)(int, int);     /* fp 是指向函数的指针 */
fp = &add;               /* & 可省略 */
int r = (*fp)(3, 4);     /* 调用；* 可省略：fp(3,4) */
```

- 声明读法：**`(*fp)`** 是函数，返回 `int`，参数两个 `int`
- **typedef** 简化：`typedef int (*binop_t)(int, int);`

### 用途

| 领域 | 例子 |
|------|------|
| 回调 | `qsort` 比较函数、`signal` 处理 |
| 内核 | 文件操作 `fops`、中断 `handler` |
| DPDK / HFT | 事件回调、策略函数表 |
| 飞控 | PID、模式切换钩子 |
| 自制 OS | 任务入口、系统调用分发表 |

### 函数指针数组

```c
int (*op[])(int, int) = { add, sub, mul };
```

逆波兰计算器扩展：按运算符下标调用 `op[c-'0'](a,b)`。

## 考点

- **`int *f()`** vs **`int (*fp)()`** —— 后者是指针
- 函数名在表达式中**退化为函数指针**（取函数地址）
- 无 `void *` 通配函数指针；不同类型函数指针需显式 cast（谨慎）
