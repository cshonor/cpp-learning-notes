# 5.9 指针与多维数组

## 本节讲什么

用**指针**遍历、传递多维数组；理解 `int (*p)[NCOLS]` 与「指针数组模拟二维」的区别。

## 要点

### 指向二维数组行的指针

```c
#define R 3
#define C 4
int a[R][C];
int (*p)[C] = a;      /* p 指向第一行，p+1 下一行 */

/* 访问 a[i][j] */
*(*(a + i) + j)
(*p)[j]              /* p 指向当前行时 */
```

### 函数参数

- 二维数组作参数必须带**列数**（除最左维外各维长度）：
  `void f(int a[][4], int nrows)` 或 `void f(int (*a)[4], int nrows)`
- 不能写成 `void f(int a[][])` —— 编译器无法缩放行宽

### 指针数组模拟二维

```c
int row0[] = {1, 2, 3};
int row1[] = {4, 5, 6};
int *rows[] = { row0, row1 };   /* 各行可不等长 */
```

## 考点

- **`a[i][j]`** 完整展开：`*(*(a+i)+j)`
- 帧缓冲：`pixel = fb[y * pitch + x]` 与二维数组行优先一致

## 与后续衔接

UEFI GOP `Blt`、Linux `fbcon` 行跨度（pitch ≥ width × bpp/8）常不等于「逻辑宽度」，偏移公式要在 5.7 公式上加 **stride**。
