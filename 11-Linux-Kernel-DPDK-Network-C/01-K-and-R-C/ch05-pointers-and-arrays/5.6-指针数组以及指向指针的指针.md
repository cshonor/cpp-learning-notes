# 5.6 指针数组以及指向指针的指针

## 本节讲什么

**指针数组** vs **数组指针** —— 全书最易混淆考点之一。前者是「元素为指针的数组」，后者是「指向整个数组的指针」。

## 要点

### 指针数组 `char *argv[]`

- 每个元素是 **`char *`**，常用来存多个字符串
- **`main(int argc, char *argv[])`** 即此结构（见 5.10）
- 等价于 `char *(argv[])` —— `[]` 优先于 `*`

### 数组指针 `int (*p)[10]`

- `p` 指向「含 10 个 `int` 的数组」
- 解引用 `(*p)[i]` 访问第 `i` 个元素
- 常见于二维数组参数、矩阵行指针

### 指向指针的指针 `char **pp`

- `pp` 指向 `char *`；`*pp` 是 `char *`，`**pp` 是 `char`
- 动态分配指针数组、改调用者指针（`void alloc(char **out)`）时使用

## 区分口诀

**括号优先**：`()` 和 `[]` 绑定名字，再与 `*` 结合。

```c
char *argv[];     /* argv 是数组，元素是 char * */
int (*p)[10];     /* p 是指针，指向 int[10] */
int *f(void);     /* f 是函数，返回 int * */
int (*fp)(int);   /* fp 是指针，指向函数（见 5.11） */
```

## 示例

```c
char *month[] = {
    "January", "February", /* ... */
};
/* month[i] 是第 i 个月名字符串 */
```

## 与后续衔接

`argv`、环境变量表、函数表（函数指针数组）都是指针数组；页表、描述符表在概念上类似「数组的数组 + 指针跳转」。
