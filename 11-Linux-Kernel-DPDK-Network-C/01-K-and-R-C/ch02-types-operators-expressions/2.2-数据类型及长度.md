# 2.2 数据类型及长度

## 本节讲什么

内置类型的**存储宽度**与**符号/无符号**语义——理解内存、寄存器、协议字段对齐的基础。

## 要点

| 类型 | 典型用途 |
|------|----------|
| `char` | 最小可寻址单元，常 1 字节 |
| `short` | 较短整型 |
| `int` | 整型运算「自然」长度，通常 32 位 |
| `long` | 更长整型；LP64 上常与指针同宽 |
| `unsigned` | 与上述组合：`unsigned int` 等，非负模运算 |
| `float` / `double` | 单/双精度浮点 |

- **`sizeof(T)`** 返回类型字节数（编译期常量）；**实现定义**宽度，移植时必须查 `<limits.h>`
- **有符号**：补码表示；**无符号**：纯模 \(2^n\)，混用易坑（见 2.7）
- `char` 是否 signed 由实现决定——内核/DPDK 常显式 `unsigned char` 处理字节

## 对你

- 读 **x86 寄存器**（`eax/rax`）、**网络字节序**、**结构体 padding** 都建立在本节类型宽度之上
- 与 C++ `int32_t` / `uint64_t` 固定宽度类型对照使用更稳
