# 2.6 关系运算符与逻辑运算符

## 本节讲什么

比较与逻辑组合：`> < >= <= == !=`、`&& || !`，以及 **短路求值** 规则。

## 要点

- 关系/相等运算结果为 **`0` 或 `1`**（C 无原生 `bool`，C99 有 `_Bool`）
- **`&&` `||` 短路**：
  - 左操作数为假，`&&` 不再求右操作数
  - 左操作数为真，`||` 不再求右操作数
- 典型用法：`if (p != NULL && p->len > 0)` —— 短路避免空指针解引用
- **`!`** 逻辑非；非零为真

## 考点

```c
if (i && f())  /* f() 仅在 i 非 0 时调用 */
if (!i || g()) /* g() 仅在 i 为 0 时调用 */
```

内核与并发代码里，短路顺序有时影响**锁的获取顺序**，需刻意避免副作用依赖。
