# 2.12 逗号运算符

## 本节讲什么

**逗号表达式** `expr1, expr2`：从左到右依次求值，**整个表达式的值为最右侧**操作数的值。

## 要点

- 逗号优先级**很低**（仅高于赋值）
- 典型合法用途：`for (i = 0, j = n-1; i < j; i++, j--)` 初始化多变量
- **`for` 头、`switch` 标签之间**的逗号是逗号表达式；**函数调用实参列表**里的逗号**不是**逗号运算符（不组成一个逗号表达式）
- 滥用：`x = (y++, z);` 可读性差，生产代码慎用

## 与宏

```c
#define MAX(a, b) ((a) > (b) ? (a) : (b))  /* 不用逗号藏副作用 */
```
