# 2.11 条件表达式

## 本节讲什么

三元运算符 **`?:`**：`expr1 ? expr2 : expr3`。

## 要点

- 若 `expr1` 非 0，整个表达式值为 `expr2`，否则为 `expr3`
- 仅 **expr2 或 expr3 之一** 被求值（类似短路）
- 常用于紧凑分支：`max = a > b ? a : b;`
- 两个分支类型会做 usual arithmetic conversion 对齐

## 示例

```c
printf("%d\n", x > 0 ? x : -x);  /* abs 雏形 */
```

## 风格

嵌套过多 `?:` 降低可读性；内核宏里常见，应用时保持一行能看懂。
