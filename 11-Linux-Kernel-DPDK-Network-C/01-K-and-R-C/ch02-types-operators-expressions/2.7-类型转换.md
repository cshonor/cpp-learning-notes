# 2.7 类型转换

## 本节讲什么

**隐式转换**（整型提升、 usual arithmetic conversions）与 **强制转换** `(type)val` —— 本章重中之重，OS/驱动/HFT 高频踩坑点。

## 要点

### 隐式提升

- 比 `int` 短的整型在运算前常提升为 **`int`**
- **usual arithmetic conversions**：二元运算前对齐到较「宽」/common 类型
- **`unsigned` 与 `signed` 混合**：规则复杂，可能把 signed 当 unsigned 解释 → 比较反转、循环死磕

### 经典坑

```c
unsigned u = 1;
int i = -1;
(u < i);  /* 可能为 0：i 转为 unsigned，变成很大的正数 */
```

### 强制转换

- `(type) expression` —— 告诉编译器按新类型解释位模式
- 指针/整数互转、截断、符号变化需极度谨慎（第 5 章、内核 `uintptr_t`）

## 对你

- **寄存器读写**、**DMA 地址**、**网络序转换** 都依赖正确理解「位不变、类型解释变」
- 优先用 **显式宽度类型** + **显式 cast**，少靠隐式规则
