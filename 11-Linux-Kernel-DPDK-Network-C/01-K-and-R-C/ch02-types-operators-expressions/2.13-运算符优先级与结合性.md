# 2.13 运算符优先级与结合性

## 本节讲什么

完整**优先级表**与**结合性**（左结合 / 右结合），解决「这式子到底先算谁」；并强调 **求值顺序** 与优先级不是一回事。

## 要点

### 优先级（高 → 低，节选）

1. `()` `[]` `->` `.` 后缀 `++` `--`
2. 一元 `! ~ ++ -- + - * & (type) sizeof`
3. `*` `/` `%`
4. `+` `-`
5. `<<` `>>`
6. 关系 `<` `>` `<=` `>=`
7. 相等 `==` `!=`
8. 位 `&` `^` `|`
9. 逻辑 `&&` `||`
10. 条件 `?:`
11. 赋值与复合赋值
12. 逗号 `,`

### 结合性

- 大多数二元运算符 **左结合**：`a - b - c` → `(a - b) - c`
- 赋值、一元、条件运算符等 **右结合**：`a = b = 0` → `a = (b = 0)`

### 求值次序

- C 保证：**&& || ?: ,** 的短路/顺序；**函数实参、多数二元运算左右谁先求值不保证**（C17 前）
- 不要写 `i++ + i++`、依赖实参求值顺序
