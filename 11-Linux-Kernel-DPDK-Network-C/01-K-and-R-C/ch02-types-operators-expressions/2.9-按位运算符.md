# 2.9 按位运算符

## 本节讲什么

对整数**按位**操作：`& | ^ ~ << >>` —— 驱动、内核、MikanOS、DPDK 必备。

## 要点

| 运算符 | 含义 |
|--------|------|
| `&` | 按位与，常用于 **mask 保留位** |
| `\|` | 按位或，**置位** |
| `^` | 按位异或，**翻转位** |
| `~` | 按位取反（一元） |
| `<<` `>>` | 左/右移；右移负数实现定义 |

### 典型用法

```c
flags \|= MASK_ENABLE;      /* 置位 */
flags &= ~MASK_ENABLE;     /* 清位 */
if (flags & MASK_READY)    /* 测试位 */
value = (word >> 8) & 0xFF; /* 取高 8 位 */
```

- 移位位数 **≥ 宽度** 或负数为 UB
- 无符号右移通常为逻辑移位；有符号右移可能是算术移位

## 对你

- **MMIO 寄存器**、**页表项 PTE 位**、**DPDK mbuf flags** 全是位域思维
- 与 2.7 结合：移位前先确认操作数是无符号还是 signed
