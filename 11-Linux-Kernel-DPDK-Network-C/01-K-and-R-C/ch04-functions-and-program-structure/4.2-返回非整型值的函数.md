# 4.2 返回非整型值的函数

## 本节讲什么

函数不必只返回 `int`：可返回 `float`、`double`、`char`、指针、结构体等。重点是 **`return` 与返回类型之间的转换规则**，以及 `void` 表示无返回值。

## 要点

- 返回类型写在函数名之前：`float atof(char s[]);`
- **`return` 表达式类型 → 自动转换为函数声明的返回类型**（与第 2 章赋值转换规则一致）
- 精度丢失示例：`int` 函数 `return 3.14f;` 得到 `3`
- **`void`**：不返回值；只能写 `return;` 或落到函数末尾
- 旧式 K&R 函数定义（无参数类型列表）仍可见于遗留代码；ANSI 原型是规范写法

## 示例

```c
double square(double x)
{
    return x * x;
}

void warn(char *msg)
{
    fprintf(stderr, "warning: %s\n", msg);
    return;   /* 可省略 */
}
```

## 考点

- 返回类型与 `return` 表达式不匹配时，编译器可能仅警告
- 返回**局部数组**非法（数组不能整体复制返回）；返回指针时生命周期问题在第 5 章详述

## 与后续衔接

HFT 策略函数常返回 `double` 价格/信号；驱动、内核里返回 `int` 错误码（0 成功、负值 errno）是惯例，与 `void` 纯副作用函数并存。
