# 4.8 程序块结构

## 本节讲什么

把小程序拆成**多个源文件 + 头文件**的**工程化组织方式**。K&R 以 **逆波兰计算器（RPN Calculator）** 贯穿本章练习，本节是整章综合：函数拆分、全局状态、`static` 隐藏、`#include` 协作。

## 要点

### 模块划分（RPN 典型结构）

| 文件 | 职责 |
|------|------|
| `main.c` | 主循环：读入、分发命令 |
| `stack.c` / `stack.h` | 栈操作 `push` / `pop` |
| `getop.c` | 解析操作数、运算符 |
| `calc.h` | 共享常量、`extern` 声明 |

### 设计原则

- **接口在 `.h`，实现在 `.c`**
- 模块内部细节用 **`static`** 隐藏（栈顶指针、缓冲区）
- 跨模块共享的最小全局状态（如 `number` 变量）显式 `extern`
- 主循环 + 函数调用，替代单文件巨函数

### RPN 逻辑概要

- 后缀表达式：`3 4 +` → 先压栈 3、4，遇 `+` 弹出两数运算再压结果
- 融合：**控制流**（第 3 章）+ **函数**（4.1）+ **外部变量**（4.3）+ **头文件**（4.5）

## 示例骨架

```c
/* main.c */
#include "calc.h"

int main(void)
{
    int type;
    while ((type = getop()) != EOF)
        switch (type) {
        case NUMBER:
            push(atof(s));  /* s 为共享输入缓冲，见书中实现 */
            break;
        case '+':
            push(pop() + pop());
            break;
        /* ... */
        }
    return 0;
}
```

## 工程映射

| 场景 | 类似拆分 |
|------|----------|
| HFT | 网络 / 策略 / 风控 / 日志 分 `.c` |
| UEFI | 协议解析 / 内存分配 / 设备驱动 分模块 |
| 飞控 | 传感器读数 / 控制律 / 通信 分文件 |

## 与后续衔接
