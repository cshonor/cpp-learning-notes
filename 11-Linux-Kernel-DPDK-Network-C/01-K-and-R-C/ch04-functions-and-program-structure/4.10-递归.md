# 4.10 递归

## 本节讲什么

函数**直接 or 间接调用自身**。写法简洁，但每次调用占用**栈帧**；必须有**终止条件**，否则栈溢出。

## 要点

- 递归 = 基线情况（base case）+ 向基线推进的递归步骤
- 每次调用：局部变量、返回地址压栈 → 深度过大 → **stack overflow**
- 经典示例：**快速排序**、树/链表遍历、**进制转换**、表达式求值

## 示例：打印整数（含负号）

```c
void printd(int n)
{
    if (n < 0) {
        putchar('-');
        n = -n;
    }
    if (n / 10)
        printd(n / 10);
    putchar(n % 10 + '0');
}
```

## 底层取舍

| 倾向递归 | 倾向迭代 |
|----------|----------|
| 树、AST、文件系统目录 | HFT 热路径、内核调度 |
| 代码短、结构贴近数学定义 | 栈深度可控、常数开销小 |
| 深度有限且已知 | 实时/嵌入式硬栈限制 |

- 内核栈通常 **8KB 量级**，深递归危险
- 可用**显式栈**（数组模拟）替代递归

## 考点

- 递归时间/空间复杂度；与循环等价改写
- 尾递归：C 编译器**不保证**尾调用优化，不能依赖
