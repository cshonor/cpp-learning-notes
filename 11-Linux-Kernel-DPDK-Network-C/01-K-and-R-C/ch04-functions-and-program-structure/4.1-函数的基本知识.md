# 4.1 函数的基本知识

## 本节讲什么

C 程序由函数构成：`main` 是入口，其余函数把逻辑拆成可复用模块。掌握完整语法、**值传递**、**声明 vs 定义**，是多文件工程与内核代码的基础。

## 要点

- 完整形式：**返回类型 函数名(形参列表) { 函数体 }**
- K&R 允许省略返回类型，默认为 **`int`**；现代 C 应显式写出
- **`return 表达式;`** 结束函数并带回值；`void` 函数用 **`return;`** 或无返回值
- 执行到函数末尾的 `}` 等价于 **`return;`**（对非 void 函数相当于返回未定义值，应避免）
- **`return` 表达式会转换为函数返回类型**，可能精度丢失（如 `float` 函数 `return 3.14` 存进 `int`）
- C 默认 **call by value（值传递）**：形参是实参的副本，函数内改形参**不影响**外部变量
- **函数声明（原型）** vs **函数定义**：调用在前、定义在后时，必须先写原型，编译器才能做**参数个数与类型检查**

## 示例

```c
int max(int a, int b)   /* 定义 */
{
    return a > b ? a : b;
}

int main(void)
{
    int m = max(3, 5);  /* 调用 */
    return 0;
}
```

```c
void swap_wrong(int x, int y)  /* 值传递：交换的是副本 */
{
    int t = x;
    x = y;
    y = t;   /* 对外部变量无效 */
}
```

## 与后续衔接

要在函数内修改调用者数据，需传**指针**（第 5 章）或改用返回值；内核里大量 `static inline` 小函数也建立在本节语法之上。
